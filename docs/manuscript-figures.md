# Manuscript Figure Remakes

The four figures in *Fire Critter for PNAS-8* can be regenerated from Python at publication size. The workflow also produces a fifth figure that tests the synthetic fire life-cycle model across perturbed parameter sets.

```bash
PYTHONPATH=src python scripts/remake_manuscript_figures.py
```

Outputs are written to `outputs/manuscript_figures/` as 400-dpi PNG, vector PDF, and SVG files. The directory also contains the Figure 4 trajectory, every Figure 5 forecast, aggregate forecast metrics, and a manifest recording the seed and model parameters.

## Evidentiary status

The generated figures do not all represent the same kind of evidence:

| Figure | Classification | What is computed |
| --- | --- | --- |
| 1 | Analytical schematic | A two-thirds perimeter-area ridge and a specified transport-matching function |
| 2 | Conceptual synthetic geometry | A rough surface, its projected footprint, and explicit hull annotations |
| 3 | Synthetic measured masks | Network, boundary, area, perimeter, and box-counting measurements from deterministic fields |
| 4 | Synthetic reduced model | Cumulative area, active perimeter, growth rate, forcing, connectivity, and edge coupling |
| 5 | Synthetic internal validation | Four-hour forecasts from past observations across 300 perturbed trajectories |

None of these figures is empirical wildfire validation. Figure 1 does not contain global fire observations, and the dimensions printed in Figures 2 and 3 must not be described as measurements of real combustion interfaces.

## Life and death model

The Figure 4 remake resolves a mismatch in the manuscript draft: the caption describes four spatial stages, while the embedded figure contains only time-series panels. The Python figure contains both.

The revised Figure 4 uses the manuscript's two-thirds metabolic closure rather than independently specified time-series curves. Its two integrated state variables are cumulative burned area `A` and coherent fuel connectivity `C`. The complete symbolic and numerical proof is executable in `notebooks/09_first_principles_fire_life_cycle.ipynb`. Every displayed line follows from:

```text
F = (A_max - A) / (A_max - A_0)
r = C / F
eta = 4r / (1 + r)^2
P_a = k C A^(2/3)
v_eff = v_0 F eta
dA/dt = v_eff P_a = beta_0 C F eta A^(2/3)
dC/dt = alpha C (1 - C) F - mu C
q = min(1, 2 eta sqrt(CF))
sigma_edge = 1/2 + q/6
```

`F` is finite connected fuel, `eta` is impedance-matching efficiency, `P_a` is coherent active perimeter, and `q` combines matching efficiency with available transport capacity. Connectivity rises through mass-action recruitment and falls through fragmentation loss as connected fuel is exhausted. This is a mechanistic reduced closure, not an ab initio combustion calculation: its equations and free parameters remain hypotheses to test.

The simulation enforces one physical bookkeeping constraint: cumulative burned area cannot decrease. Fire "death" therefore means that active perimeter, metabolic rate, coupling capacity, and connectivity collapse while final burned area approaches a plateau. The four stages are detected from the simulated signals rather than placed at arbitrary illustration times.

The exported `figure4_life_cycle_trajectory.csv` contains every plotted variable and the stage markers.

## Robustness and prediction

The internal validation perturbs ignition area, total connected fuel, initial connectivity, connectivity recruitment and loss, metabolic scale, perimeter coefficient, and energy per area over 300 deterministic-seed runs. All 300 runs preserve monotonic cumulative area and ordered coupling, acceleration, peak, and fragmentation stages.

Prediction is not uniformly good across stages. Median absolute percentage error for four-hour area forecasts is:

| Forecast origin | Best tested rule | Median absolute percentage error |
| --- | --- | ---: |
| Accelerating | Cube-root area (`sigma = 2/3`) | 39.41% |
| Peak | Linear area (`sigma = 0`) | 10.73% |
| Declining | No growth | 7.99% |

This supports a phase-dependent interpretation, not a universal two-thirds forecasting law. The two-thirds transform improves on simpler rules during acceleration but overpredicts after the peak. A predictive system therefore needs a leakage-resistant stage or regime detector before selecting a growth closure.

The result is an internal consistency check because the data are generated by the same model family being examined. Real predictive evidence still requires an untouched event-level test with observed perimeter or another justified proxy for edge state.

## SI handoff report

The proof, numerical checks, synthetic validation, summary statistics, and complete code listings can be regenerated as one SI-ready report:

```bash
MPLCONFIGDIR=tmp/matplotlib-cache PYTHONPATH=src \
  python scripts/build_first_principles_si_handoff_pdf.py
```

The report is written to `output/pdf/first_principles_fire_life_cycle_si_handoff.pdf`. It includes five diagnostic figures: the canonical trajectory, exact closure residuals and recovered two-thirds slope, phase-stratified forecast errors, 1,000-run outcome distributions, and a rank-based parameter sensitivity matrix. The appendices preserve the complete notebook cells, production model, QA/statistical routines, and automated tests used to produce the report.
